Para realizar este apartado me apoye totalmente en el auxiliar 10 del curso orientado 
a Spring Boot y como se dice en el video de este mismo, solo aplicamos Spring Boot para la parte de busqueda y nada más, por esto mismo separo los dos archivos de la tarea 3 y 4.

## Funcionamiento
Se tiene que levantar la Aplicacion del lado de la Tarea_3, es decir: 

cd Tarea_3 \
python -m venv venv \
pip install -r requeriments.txt \
python flask_app/app.py

Y por el lado de la tarea, solamente presionar 'Run' en el archivo de "Tarea4Application.java"
Con estas dos cosas hechas, deberia funcionar de buena manera la Tarea en cuestión.
